# Student mangement & CGPA Dashbord
 a python-based student management System built using  Streamlit and SQLite 

 ## Feature 
 - Add students
 - view students
 - Delete students
 - add students marks
 - calculate grades
 - Calculate SGPA 
 - Students performance dashbord 
 - SGPA visualization 
 - SQLite database

 ## Technologies Used
 - python 
 - Streamlit
 - SQLite 
 - Pandas
 - Git 
 - GitHub
